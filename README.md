# Дневной лимит

AI-финансовый помощник для студентов 18–25 лет с нерегулярным доходом.

**Кейс 1 — AI в личных финансах · Стартап-хакатон 2026 · Т-Банк**

---

## Проблема

Студенты с нерегулярным доходом не понимают, сколько можно безопасно тратить до следующего поступления. Деньги уходят мелкими импульсивными тратами, накопления не формируются, финансовые риски остаются незамеченными.

## Решение

AI-ассистент, который:

- считает **безопасный дневной лимит** трат до следующего поступления (код);
- разбивает траты по категориям и показывает перерасход (код);
- считает прогресс к цели накопления (код);
- находит финансовые риски и риски по кредитке (код);
- объясняет результат простым языком (GigaChat или offline-шаблоны);
- объясняет термины через RAG с указанием источника;
- корректно отказывает на инвестиционные советы и операции с деньгами.

**Все суммы, проценты и остатки считаются Python-кодом. LLM только формулирует объяснение.**

## Что соответствует кейсу

| Требование кейса | Реализация |
|------------------|------------|
| Один сегмент 18–25 | Студенты с нерегулярным доходом |

| MVP с взаимодействием | Web UI: лимит, траты, цель, риски, чат |

## Технологии

- **Backend:** FastAPI, Python 3.13
- **Frontend:** HTML / CSS / JS (стилистика Т-Банка: тёмный + жёлтый)
- **LLM:** GigaChat (опционально).
- **Tool Calling:** инструменты вызываются из агента, расчёты только в Python
- **Данные:** синтетические JSON-профили (без реальных счетов)
- **RAG:** локальная база терминов (Банк России, Финуслуги и др.)

## Запуск локально

```bash
cd daily-limit-assistant   # или корень репозитория
python -m venv venv
# Windows: venv\Scripts\activate
source venv/bin/activate
pip install -r requirements.txt
cd backend
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

Открой в браузере: **http://127.0.0.1:8000**

Фронтенд и API с одного origin. Без ключа GigaChat чат отвечает по правилам + результатам tools.

## Демо-сценарии

1. Выбрать профиль **Аня** → на главном экране дневной лимит и подсказка.
2. Чат: «Сколько я могу потратить сегодня?» → tool `calculate_daily_limit`.
3. «Куда уходят деньги?» → категории и перерасход.
4. «Как я иду к цели?» → прогресс накопления.
5. «Что такое льготный период?» → RAG + источник.
6. «Посоветуй акции» / «Переведи 5000» → отказ по правилам.
7. Профиль **Илья** → «Недостаточно данных» (нет даты следующего поступления).
